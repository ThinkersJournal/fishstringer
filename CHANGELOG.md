## 0.10.1 — Slang `lower`: multi-output and hetero (u8 keep-mask) out-dtype plans, for interface callers

`Slang::lower_with` no longer refuses a plan with several outputs or an output whose dtype differs from the compute dtype (the u8
keep-mask of a dropout-class op). Like a runtime `Param`, such a plan changes the resource list the caller binds, so a legacy
caller is still refused (`UnsupportedPlanShape`, naming `CallerCaps::with_interface()`), and an interface caller gets explicit
`[[vk::binding]]` slots (inputs, then `output0..`, then the `Params_` block last), the `n` field and bounds guard, and a
`KernelInterface` whose per-output buffer dtype is `out_dtype_of(j)`. A single uniform output keeps its historical text and name
`output`. The bodies share one DAG (a value used by two outputs is computed once); the u8 conversion is applied at its own store,
never inside the shared node. A u8 output is declined with a typed error on a target that advertises no 8-bit arithmetic.
Verified: `tests/lower_multi_output.rs`, including slangc compiling both shapes and its reflected binding slots and `Params_`
offsets equalling the stated interface. NOT verified: a device run; the `fishstringer-slang-parse` lifter does not yet read the
multi-output form.

## 0.4.4 — `Slang::lower_module` grows buffer arguments, `CallTuple`, extern `spirv_asm` bodies and allocation arguments (E16, slices 2-5)

- **Buffer arguments.** A `Call` may pass the caller's buffer parameter (`CallArg::Buffer`) to a callee's buffer parameter. The Slang callee takes the binding and its strides and base as parameters (`RWStructuredBuffer<T> b<i>, int64_t b<i>_stride<d>…, int64_t b<i>_base`). The buffer's rank must be declared.
- **`CallTuple`.** A callee with `KernelFn::results` returns a struct `R<index>` (fields `v0, v1, …`, the first being `result`); `Stmt::CallTuple` unpacks it, a plain `Call` takes `.v0`. A results list of the wrong length is a typed decline.
- **Extern asm.** An `ExternCall` whose declaration has no `reference` but a `TargetBody` keyed `"slang"` with `BodyText::Asm` lowers to a Slang function `e<decl>` whose body is a `spirv_asm { … }` block (operands `{i}` become `$p<i>` and `result`). A reference still wins.
- **Allocation arguments.** A `Call` may pass a `Shared` or `Private` allocation (`CallArg::Alloc`) to a rank-1 buffer parameter as (array, stride 1, base 0); a callee passed an allocation at any call site takes that buffer as a generic `IRWArray<T>`.
- Still named declines: `Symbol` bodies, an `Asm` keyed to another target, `Constant` allocation arguments, several extern results, 16-bit float buffers in a callee. slangc-compiled in tests, not device-run.

## 0.4.1 — `Slang::lower_module` lowers a module's entry kernel with the helper functions and externs it calls (row 17 E16, first slice)

New public method `Slang::lower_module(&Module, entry)`: `Backend::lower_kernel` takes one `KernelFn` and cannot see a module, so the call constructs get their own entry point. The module goes through `check_module` first (acyclic call graph, valid callees). Every function the entry reaches is emitted callee-first as a Slang function `f<index>`; a `Stmt::Call` with scalar arguments becomes `l<r> = f<k>(args)`, and a `Stmt::ExternCall` whose declaration has a `reference` kernel emits a call of that reference body (the declaration's semantics by construction). Typed declines, reason starting `slang: `: an extern with no reference (`slang: ExternCall: no Slang body for extern `X``; `Asm` and `Symbol` bodies are not read in this slice), a buffer or allocation argument, `CallTuple`, a tuple-result callee, a callee with a launch, an allocation, a 16-bit float, or a read of a launch id. The gap scan runs on every reachable function. `lower_kernel` is unchanged. ## 0.3.7 — `lower_kernel` lowers 64-bit locals and Cast; a paged gather compiles (row 17 E13)

## 0.3.6 — `lower_kernel` lowers f16 and bf16 buffers, locals and arithmetic (row 17 E11)

`Slang::lower_kernel` now accepts `F16` and `Bf16` kernels. `F16` is Slang's `half` throughout (constants as `((half)x)`). `Bf16` has no Slang scalar, so a bf16 buffer is `StructuredBuffer<uint16_t>` read through `bf16_to_f32_` and written through `f32_to_bf16_` (round to nearest even, NaN stays a quiet NaN), bf16 locals and shared/private arrays are `float` holding a bf16-representable value, and every bf16 `Add`/`Sub`/`Mul` is rounded back with `bf16r_`; the generated source carries the three helpers and the float `-denorm-mode-fp32 preserve` argument. A 16-bit float scalar parameter, packed (multi-lane) locals and fp8 still decline. An f16 and a bf16 `x*2+y` kernel compile to SPIR-V with `slangc` (required, not skipped). Not run on a device, so the bf16 rounding is not yet compared exhaustively against the oracle. Additive.

## 0.3.5 — `lower_kernel` lowers integer atomics (row 17 E10)

`Slang::lower_kernel` now lowers `AtomicRmw` (`Add`, `Max`, `Min`, `And`, `Or`, `Xor`, `Exchange`) as `InterlockedAdd/Max/Min/And/Or/Xor/Exchange(dest, value[, old])` and `AtomicCas` as `InterlockedCompareExchange(dest, expected, desired[, old])`, on an `I32`/`U32` buffer element or `groupshared` element, with the optional old value in a local. ## 0.3.4 — `lower_kernel` lowers lane, subgroup and device ids (row 17 E12)

`Slang::lower_kernel` now lowers the remaining execution ids: `LaneId` is `WaveGetLaneIndex()`, `SubgroupSize` is `WaveGetLaneCount()`, `SubgroupId` is derived as `SV_GroupIndex / WaveGetLaneCount()` (the entry point gains an `SV_GroupIndex` argument), and `DeviceRank`/`DeviceCount` are the constants 0 and 1 (a multi-device launch is already a named gap). ## 0.3.3 — `lower_kernel` lowers barriers and fences (row 17 E7)

`Slang::lower_kernel` now lowers `Barrier{Block}` to `GroupMemoryBarrierWithGroupSync()`, `Barrier{Subgroup}` to `AllMemoryBarrierWithWaveSync()`, and `Fence` at block, subgroup and device scope to `GroupMemoryBarrier()`, `AllMemoryBarrier()` and `DeviceMemoryBarrier()`. ## 0.3.1 — `lower_kernel` lowers control flow, masked access and comparisons (row 17 E4)

## 0.3.0 — **BREAKING**: `lower_kernel` buffers are strided views with a parameter block (row 17 E2)
