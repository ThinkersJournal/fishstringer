kind: CI: install a pinned dxc and make the HLSL compile assertions fatal without it
---
The `slang-emit` job downloads Microsoft's DirectXShaderCompiler release v1.9.2609 (`linux_dxc_2026_09_28.x86_x64.tar.gz`), checks its sha256 (`96faadc7...a39a1`, the digest GitHub records, re-computed by hand from a download on 2026-11-26) and sets `FISHSTRINGER_REQUIRE_DXC=1`, so the dxc assertions of `lower_kernel_hlsl_collectives` fail instead of skipping when dxc is absent. Nothing of dxc is vendored or redistributed (a CI download), so no THIRD-PARTY-NOTICES entry is added. UNMEASURED: the Linux asset has not been run by this lane (only the 1.9.0.5347 Windows dxc ran the assertions locally); the first CI run of this change is its first measurement, and a red-first run (the same job without the install step) is not done. Shader model 6.6 is the minimum for the plain HLSL (`[WaveSize]`; vulkane measured an error at cs_6_0 and cs_6_5).
