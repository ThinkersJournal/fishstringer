kind: **BREAKING**: `lower_kernel` buffers are strided views with a parameter block (row 17 E2)
---
`Slang::lower_kernel` now lowers scalar parameters (`F32`/`I32`/`U32`) and buffers of any declared rank as strided views: element offset `base + sum(coord_d * stride_d)` in `int64_t`, with every stride, base and scalar in one `ConstantBuffer` bound after the buffers. **Breaking for consumers of the 0.2.0 interface:** a rank-1 buffer is no longer a flat index, so every lowered kernel now carries a `ParamsBlock` (fields `b<i>_stride<d>`, `b<i>_base`, `p<i>`, `int64_t` strides/bases) and buffer binding slots are dense in buffer order. A buffer with no declared rank is declined. No shape field and no bounds check is emitted; the block needs `shaderInt64` (fidelity note on the interface). Verified: a new test compares the stated `ParamsBlock` offsets and size with `slangc -reflection-json`, and fails when the sizes are mutated; slangc compiles both kernels to SPIR-V; workspace tests and `clippy -D warnings` pass. Not run on a device.
