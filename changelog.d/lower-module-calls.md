kind: `Slang::lower_module` lowers a module's entry kernel with the helper functions and externs it calls (row 17 E16, first slice)
---
New public method `Slang::lower_module(&Module, entry)`: `Backend::lower_kernel` takes one `KernelFn` and cannot see a module, so the call constructs get their own entry point. The module goes through `check_module` first (acyclic call graph, valid callees). Every function the entry reaches is emitted callee-first as a Slang function `f<index>`; a `Stmt::Call` with scalar arguments becomes `l<r> = f<k>(args)`, and a `Stmt::ExternCall` whose declaration has a `reference` kernel emits a call of that reference body (the declaration's semantics by construction). Typed declines, reason starting `slang: `: an extern with no reference (`slang: ExternCall: no Slang body for extern `X``; `Asm` and `Symbol` bodies are not read in this slice), a buffer or allocation argument, `CallTuple`, a tuple-result callee, a callee with a launch, an allocation, a 16-bit float, or a read of a launch id. The gap scan runs on every reachable function. `lower_kernel` is unchanged. Tests (`tests/lower_module_calls.rs`, written red first) compile the call and extern outputs with `slangc` and pin each decline, with controls (the same extern with a reference lowers; a cyclic module is refused by the checker); `cargo test --workspace` and `cargo clippy --workspace --all-targets -D warnings` pass with `FISHSTRINGER_REQUIRE_SLANGC=1`. Not device-run. Additive.
